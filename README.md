# Air Canvas 🎨

A virtual drawing application that allows users to draw in the air using hand gestures.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Features
- Draw using hand gestures
- Clear the canvas
- Save drawings as PNG
- Change brush size

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python air_canvas.py
```

## Keyboard Controls
- C: Clear canvas
- S: Save drawing as PNG
- + / -: Change brush size
- Q or ESC: Quit application
